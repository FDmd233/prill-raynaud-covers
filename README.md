# Prill-Exceptional Étale Covers from Raynaud Bundles

This repository contains a short preprint on Prill's problem for smooth projective complex curves. For every curve of genus $g\ge 2$, it constructs a connected finite étale Galois cover for which every fibre divisor moves in a pencil.
